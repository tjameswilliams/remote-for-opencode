# Repo conventions

## Writing style

- Never use em dashes (—) anywhere in this repo: website copy, docs, marketing
  text, App Store metadata, code comments, commit messages. Rewrite the
  sentence with a comma, colon, semicolon, period, or parentheses instead.
- The product is free and source-available (PolyForm Noncommercial). Do not
  describe it as "open source" in copy unless the license changes to an
  OSI-approved one.
